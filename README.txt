BIZPRO BUSINESS WEBSITE MOCKUP

Files:
- index.html : Website structure (HTML)
- style.css  : Styling and responsive layout (CSS)

How to run:
1. Extract the ZIP file.
2. Open the business-website-mockup folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

Sections included:
- Navbar with logo and responsive mobile menu
- Hero section with heading, description, button and illustration
- Services cards (Web Design, Digital Marketing, SEO Optimization)
- About section
- Contact information and contact form demo
- Footer
- Responsive design for desktop, tablet and mobile

Note: The contact form is front-end demo only. It does not send messages to a server.
